# Habit Tracker

A simple and interactive Habit Tracker Web Application built using HTML, CSS, JavaScript, and Chart.js. This application helps users build positive habits, track daily progress, maintain streaks, earn points, and analyze their habit completion performance through statistics and visual charts.

## Live Demo

https://msupraja04.github.io/Habit-Tracker/

## Project Overview

Building and maintaining good habits is challenging for many people. This Habit Tracker helps users stay consistent by tracking daily activities, monitoring streaks, and providing visual feedback on progress.

Users can create habits, categorize them, mark them as completed, and view their overall performance through progress indicators and analytics.

## How It Works

1. Enter a habit name.
2. Select a category.
3. Click "Add Habit".
4. Mark habits as completed using the Done button.
5. Earn points and increase streak count.
6. Monitor daily progress and statistics.
7. View weekly analytics through the chart.
